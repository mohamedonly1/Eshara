🌟 الفكرة العامة: كيف يعمل التطبيق؟

قبل الدخول في الأكواد، دعنا نفهم كيف تترجم الآلة إشارات اليد:

التقاط الفيديو

الكاميرا تلتقط صوراً متتالية ليدك بشكل مستمر وسلس.

1

تحليل باستخدام MediaPipe

مكتبة MediaPipe من Google تكتشف اليد وتحدد 21 نقطة رئيسية (مفاصل وأطراف أصابع) بأبعاد ثلاثية X, Y, Z.

2

تطبيع البيانات

نقوم بتطبيع البيانات (Normalization) لجعلها نسبية للمعصم، حتى لا تتأثر بموضع اليد أو بعدها عن الكاميرا.

3

معالجة الميزات

نستخرج 62 ميزة مشتقة تتضمن زوايا ومسافات بين المفاصل لإعطاء النموذج معلومات دقيقة جداً.

4

التنبؤ بالحرف

نمرر البيانات لنموذج TFLite المدرب مسبقاً والذي يحلل العلاقات الرياضية بين النقاط ويتوقع الحرف العربي.

5

العرض والنطق

يتم عرض الحرف على الشاشة ونطقه صوتياً باستخدام Text-to-Speech لمساعدة الصم والبكم.

6
💡 نقطة مهمة: النموذج الحالي يغطي 29 حرف عربي كاملاً (تطور كبير من البدايات!). لكن تم اكتشاف مشكلة data leakage في التقييم الحالي، مما يعني أن الدقة الحقيقية قد تكون أقل قليلاً. الخطوة التالية هي استخدام Cross-User Evaluation لقياس الأداء الحقيقية.

نظام الحماية من هجمات CSRF

لحماية الموقع من الهجمات، نستخدم CSRF Tokens:

// JavaScript - إضافة التوكن تلقائياً لكل طلب
(function() {
    function getCsrfToken() {
        const match = document.cookie.match(
            /(?:^|;\s*)csrf_token=([^;]*)/
        );
        return match ? decodeURIComponent(match[1]) : '';
    }
    
    const _originalFetch = window.fetch;
    
    window.fetch = function(url, options) {
        options = options || {};
        const method = (options.method || 'GET').toUpperCase();
        if (method !== 'GET' && method !== 'HEAD') {
            options.headers = options.headers || {};
            options.headers['X-CSRFToken'] = getCsrfToken();
        }
        return _originalFetch.call(this, url, options);
    };
})();
