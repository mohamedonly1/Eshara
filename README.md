# مشروع إشارة - التعرف على لغة الإشارة العربية الموحدة
# Ishara - Arabic Sign Language Recognition System

---

## نظرة عامة على المشروع

"إشارة" هو نظام متكامل مصمم لسد الفجوة في التواصل بين مجتمع الصم والبكم والمجتمع العام. يعتمد النظام على تقنيات الذكاء الاصطناعي المتقدمة (AI) والرؤية الحاسوبية (Computer Vision) للتعرف على الإيماءات وترجمتها في الوقت الفعلي.

تطور المشروع من مجرد سكربت بايثون ليصبح **منظومة متكاملة** تتكون من ثلاث منصات رئيسية:
1. **تطبيق أندرويد (Android App)**: للترجمة الفورية عبر كاميرا الهاتف.
2. **منصة الويب (Web Dashboard)**: تحتوي على قاموس إشارات ونظام ترجمة عكسي باستخدام مجسم ثلاثي الأبعاد (3D Hand Model).
3. **نظام الذكاء الاصطناعي (AI Pipeline)**: لجمع البيانات وتدريب الشبكات العصبية.

---

## 📱 1. تطبيق الأندرويد (Ishara App)

تطبيق مخصص للهواتف الذكية يوفر ترجمة فورية للغة الإشارة باستخدام الكاميرا.

- **التقنيات**: Kotlin, CameraX, MediaPipe Tasks Vision, TensorFlow Lite.
- **المميزات**:
  - **ترجمة في الوقت الفعلي (Real-time)** باستخدام الكاميرا الأمامية والخلفية.
  - **معالجة متقدمة للصور**: نظام معقد لتصحيح زوايا الدوران (Rotation Degrees) وتعديل نسبة الأبعاد (Aspect Ratio) لضمان تطابق إحداثيات كاميرا الهاتف (Portrait) مع بيئة تدريب الموديل (Landscape)، مما أدى إلى دقة استنتاج (Inference) عالية جداً.
  - **رسم دقيق (Overlay)**: رسم النقاط (Landmarks) على اليد بدقة متناهية مع دعم تأثير المرآة (Mirroring) للكاميرا الأمامية.
  - دعم الإدخال الصوتي والترجمة إلى نص.

---

## 🌐 2. منصة الويب والأنيميشن ثلاثي الأبعاد (Web & 3D System)

تطبيق ويب متكامل يعمل كلوحة تحكم ومترجم تفاعلي.

- **التقنيات**: Python, Flask, Three.js, JavaScript.
- **المميزات**:
  - **قاموس إشارات 3D**: نظام يعتمد على Inverse Kinematics (IK) لتحريك مجسم يد ثلاثي الأبعاد (GLB Model) بدقة لتمثيل الحروف والكلمات.
  - **خوارزميات تصحيح العظام**: تم حل مشاكل تشوه العظام (Deformation) عبر حسابات رياضية دقيقة لتحويل إحداثيات MediaPipe إلى زوايا دوران صحيحة للمجسم.
  - **لوحة تحكم للإدارة**: تسمح بتعديل معايرة اليد (Calibration)، إدارة الحروف، وتتبع التعديلات.
  - **ترجمة بالنظام الصوتي**: تحويل الكلام المسموع إلى نص ثم إلى إشارات ثلاثية الأبعاد.

---

## 🧠 3. الذكاء الاصطناعي وتدريب الموديل (AI Pipeline)

النواة الأساسية للمشروع والتي تقوم بالتعرف على الإيماءات.

- **التقنيات**: MediaPipe, TensorFlow/Keras, OpenCV, Scikit-Learn.
- **معمارية النظام**:
  1. **اكتشاف اليد**: استخراج 21 نقطة مفصلية باستخدام MediaPipe.
  2. **المعالجة المسبقة**: تحويل النقاط إلى إحداثيات نسبية وتطبيعها (Normalization) لجعل الموديل مستقلاً عن حجم ومكان اليد في الصورة.
  3. **الشبكة العصبية (MLP)**: شبكة مكونة من عدة طبقات (Dense) مع (BatchNormalization و Dropout) لتصنيف الإيماءة إلى واحد من 29 حرفاً أبجدياً.
- **النتائج**: دقة تجاوزت **95.96%** على بيانات اختبار متنوعة، وتم تحويل الموديل إلى صيغة `TFLite` المدمجة ليعمل على الهواتف بكفاءة وسرعة.

## هيكل المشروع الحالي

```
ishara-project/
│
├── Ishara/                  ← تطبيق الأندرويد (Android Studio Project)
│   ├── app/src/main/java/   ← أكواد Kotlin و CameraX
│   └── app/src/main/assets/ ← موديل TFLite وقوائم الحروف
│
├── static/                  ← ملفات الويب (CSS, JS, Three.js)
├── templates/               ← واجهات الويب (HTML)
├── server.py                ← خادم Flask للويب
│
├── collect_data.py          ← أداة جمع بيانات التدريب
├── train_model.py           ← سكريبت تدريب الموديل الأساسي
├── languages_data/          ← بيانات لغات الذكاء الاصطناعي (مفصولة لكل لغة في مجلد خاص بها)
├── users_data/              ← بيانات المستخدمين وسجلات نشاطهم (مفصولة عن بيانات اللغات)
└── arabic_model/            ← النماذج المدربة (H5 & TFLite)
```

## متطلبات التشغيل الأساسية للبيئة

- Python 3.10
- Node.js (لإدارة بعض حزم الويب إن لزم)
- Android Studio (لتشغيل تطبيق الأندرويد)

**لتشغيل خادم الويب والتدريب:**
```bash
pip install mediapipe==0.10.11 tensorflow==2.10.1 numpy==1.26.4
pip install opencv-contrib-python Flask scikit-learn matplotlib
 ```
